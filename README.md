# CASE028 · аналіз ускладнень терапії

Окрема навчальна демонстрація аналізу небажаних явищ онкологічної терапії. Репозиторій і сайт незалежні від основного сайту HematoBoard; інтерфейс походить із його експериментального модуля ускладнень.

[Відкрити демонстрацію](https://esannikov.github.io/case028-treatment-safety/)

## Що містить демонстрація

- Знеособлена історія випадку та 11 клінічних епізодів.
- Лабораторна динаміка з точними джерелами, статусами референсів і зіставними рядами.
- Окрема оцінка тяжкості, серйозності, причинного зв’язку та перебігу.
- Аргументи, альтернативні пояснення й 17 кроків уточнення для лікарського перегляду.

Синтез є кандидатним: клінічне прийняття не записане. Демонстрація не встановлює клінічної ефективності системи або новизни висновків для лікарів. Вхідна база вже містила попередню карту побічних ефектів.

## Дані й джерела

Опубліковано за прямим дорученням власника проєкту. Пакет пройшов технічну перевірку знеособлення; це не позначено як виконану людиною верифікацію. Оригінальні медичні файли, прямі ідентифікатори, приватні шляхи, записи робочих сесій та PDF настанов у репозиторій не включені. Джерельні уривки в інтерфейсі походять зі знеособленої наданої бази.

Наведені короткі положення настанов і посилання на першоджерела. Документи NCCN та інших правовласників не розповсюджуються; їхні права та умови доступу зберігаються. Окремої відкритої ліцензії на код проєкту або клінічний набір даних не надано. Залежності використовуються за власними ліцензіями.

## Локальний запуск

Потрібні Node.js 24 або новіший сумісний випуск і Python 3 для перевірки дозволу на публічне відображення.

```sh
npm ci
npm run verify
npm test
npm run dev
```

```sh
npm run build
npm run preview
```

`npm run verify` перевіряє хеші публічних файлів, точну версію клінічного синтезу й дозвіл на публікацію. Реліз є зафіксованим знімком: він не підключається до актуального медичного запису чи локального API HematoBoard.

GitHub Actions перевіряє пакет, запускає тести, збирає Vite і публікує `dist` у GitHub Pages. Усі дії зафіксовані на конкретних commit SHA.

## Походження публічного знімка

`patient-graph.json` є мінімальною UI-проєкцією: збережено ідентичності та версії всіх об’єктів, джерельні застереження й компонент епізодів. Клінічні значення та тексти доступні у `case-package.json`. Персональні, географічні та адміністративні ідентифікатори прибрано з публічних джерельних уривків. Клінічні значення, дати, статуси та синтез збережено. `release.json` містить перелік перетворень без прихованих ідентифікаторів або їхніх первинних текстових хешів. Приватний канон не змінено. Ідентичності, версії й хеші сутностей посилаються на канонічні джерела; публічні цитати додатково знеособлені, а цілісність цієї проєкції визначають хеші файлів релізу.

Дозвіл на публічне відображення зв’язаний із точним серіалізованим пакетом; `verify-display.py` повторно перевіряє цей зв’язок і всі положення джерел. Це запис дозволу на оприлюднення, а не лікарське прийняття висновку чи нова ліцензія на документи третіх осіб.
